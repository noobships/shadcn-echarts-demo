# Contributing

Thanks for your interest in improving this demo.

This repository is intentionally focused: it exists to help developers understand real-world usage of `@devstool/shadcn-echarts` inside a Next.js project.
It is maintained under the `noobships` account as part of the `devstool` brand.

## Local Setup

### Prerequisites

- Node.js 20+
- pnpm 10+
- Git

### Run Locally

```bash
git clone https://github.com/noobships/shadcn-echarts-demo.git
cd shadcn-echarts-demo
pnpm install
pnpm dev
```

## Contribution Scope

- Keep changes aligned with demo/education value
- Prefer clear, typed examples over clever abstractions
- Avoid adding unnecessary dependencies
- Keep UI and docs minimal and readable

## Before Opening a PR

Run:

```bash
pnpm lint
pnpm lint:oxlint
pnpm build
```

## Pull Requests

- Use a focused branch per change
- Explain what changed and why
- Include screenshots for UI-visible changes
- Link related issues when applicable
